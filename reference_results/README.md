# 原研究对照结果

这些JSON复制自原研究归档，仅用于比较和溯源，不会由一键入口当作新训练结果读取。主要原记录为主搜索60/60目标族与系数通过、13次严格恒等；采样原始77/80目标族通过；双变量main为2/5、focused为4/5。追加及稀疏化单独报告。

`summary.json`为原汇总，`generator_verification.json`为原生成器核验，`joint_verification.json`为原双变量独立核验，`archive_audit.json`为原文件完整性记录，`provenance.json`为导入源码及原方案文档哈希。旧归档中的路径若出现，表示来源，不是新程序的运行依赖。
