# 原增强实验的冻结参照

此目录保存2026年11月20日增强批次的小型摘要，不保存训练数据、模型检查点或完整日志；不被运行入口读取为训练、初始化或新运行结果。

- `confirmed_configuration.json`：当时确认的3600秒增强配置。
- `grouped_statistics.csv`：按批次、方法、场景与SNR分开的原分组统计。
- `harmonic_successes.csv`：原第1—10阶谐波的5%/10%通过次数。
- `source_audit.json`：原批次的数值核验和源文件哈希。该核验针对当时的研究代码，不替代当前仓库的迁移测试。

原无噪声最终确认3/5次同时达到独立域内1%、域外5%、基频和二次谐波各5%的基础标准，域外NRMSE中位数约0.01656。三、四、五次谐波在10%误差标准下分别通过3/5、3/5、2/5次。50/40/30 dB联合通过1/5、0/5、0/5；独立成本的无噪声非线性组另有4/5次最终模型通过，不并入确认批次。

`legacy_W0_600`行是更早批次的历史对照，不是本轮新增搜索。原确认、探索、噪声和效率分开统计。新运行的所有指标由其`runs/<name>/supplemental_study/summary/`实时生成，不能要求随机搜索逐位复现这些历史数字。
