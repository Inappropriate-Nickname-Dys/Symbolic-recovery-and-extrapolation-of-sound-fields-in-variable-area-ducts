# 实验设置和统计口径

## 数值模型与样本

使用无损一维Webster方程，归一化声压初值为`P(0)=1`、`Pξ(0)=0`，`ξ=x/L`、`κ=kL`、`μ=mL`、`b=x₀/L`。四构型为等截面、圆锥、指数及悬链线。三组配对参数依次为`(κ,μ,b)=(8π,0.8,0.35)、(10π,1.4,0.65)、(12π,2,1)`。

标签来自DOP853，`rtol=1e-11`、`atol=1e-13`、稠密输出；解析式只用于生成器检查及后验认证。主实验160个训练点在`[0,0.4]`，240个独立ID验证坐标同属该区间，测试为全场2001点中的`ξ>0.4`。输入为已知波数缩放后的空间相位`t=κξ`。随机布点固定两端点，内部点按运行种子抽样。

## PySR与候选选择

单变量算子为`+ - * / sin cos exp cosh`，最大树节点40、深度14，32个种群×64个个体，迭代上限10000、每迭代600内部循环，float64。复杂度惩罚`1e-6`、节点数预热比例0.05，常数优化50轮、4次重启、概率0.25。超越函数自变量最多7节点，禁止彼此嵌套。原始搜索180秒、4线程，种子0至4；训练MSE低于`1e-20`且复杂度不超过40可早停。

每个候选只用训练点精修已有浮点常数，ID验证选取误差在`max(1e-16,1.1*最佳验证MSE)`内复杂度最低者。选择快照先落盘，再评价OOD。SciPy常数精修使用`least_squares`、三点差分Jacobian、最多1200次函数评价，三项停止容差均`1e-13`。优化常数不是把系数投影为理论值。

双变量圆锥输入`t,η=kx₀`。训练η为15/18/21/24/27/30，各160个`t∈[0,4π]`点；验证η为16.5/19.5/22.5/25.5/28.5，各129个独立t点。相位OOD为`(4π,10π]`，几何OOD的η为8/10/12/14/31/34/37/40，联合OOD同时外推两轴。

双变量原始配置为40×80种群、预热比例0.02、600秒预算，其余同一维。focused保留`+ * / sin cos`，三角函数自变量最多3节点，常数优化100轮，其余容量及种群保持；5个种子各600秒。种子1的独立追加采用900秒和16线程。

## 对照及后处理

MLP为三层64单元tanh，float64，训练输入标准化。Adam初始学习率`1e-3`，最多12000步，验证早停1500步；学习率调度patience为300、衰减0.5、下限`1e-5`。最佳验证检查点再接受训练点LBFGS最多500步，并按ID验证决定接受。统一精修再追加最多3000步LBFGS，原模型保留。

一维Chebyshev阶数为6/10/14/18/22/26，以ID验证选择。双变量最终对照使用t方向上述六阶、η方向1至5阶的30组张量积，训练最小二乘和验证选阶，记录秩及条件数；早期总阶拟合保留。`Modal informed`是历史数据标签，表示已知正确几何包络和有效波数的两系数基函数拟合，并非求解本征模态。

独立族认证要求结构及理论系数通过，容差为`1e-6*max(1,abs(理论值))`；严格恒等分列。稀疏化将绝对值小于`1e-10`的非零自由浮点常数置零，再训练点精修，仅在原ID容差内且符号运算数减少时接受。稀疏化属于新模型，不覆盖原搜索指标。

## 指标

NRMSE为区域RMSE除以同一区域真实声压RMS，另报告MAE、最大误差和分段OOD。可用外推距离为累计OOD NRMSE连续不超过1%的最长距离，步长0.05。节点/极值采用统一2001点网格三次样条、匈牙利匹配及四分之一波长阈值，最终统一排除距0.4及1小于`1e-6`的边界根，报告漏检、误检及位置差。

连续模型的物理残差使用符号/解析导数或MLP自动微分。声压数值吻合、函数族恢复、严格恒等和物理一致性是不同指标。检查器同时记录有限误差数量，不能仅用忽略非有限值后的中位数表示全体成功。
