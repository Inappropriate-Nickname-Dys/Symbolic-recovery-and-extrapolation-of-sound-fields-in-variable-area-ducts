# 代码整理范围与来源

原归档为服务器`Acoustic_Technique`。本仓库从其中导入13个科学计算和检查模块，14份任务清单的JSON任务定义不变，文本换行统一为LF；原源码的SHA256及导入后对应路径在`reference_results/provenance.json`记录。`imported_sha256`记录自动导入时、Black格式化之前的源码；最终运行所用源码哈希另由各工作区的`docs/reproduction_provenance.json`记录。

调整包括模块相对导入、统一输出路径、以`python -m`调度、双环境及Julia配置、锁和冻结记录、从仓库源目录计算代码指纹。科学方程、标签、采样、算子与预算、训练/候选选择、证书和稀疏化接受规则保留。新入口将数据和模型写入`runs/<名称>`，代码与生成产物分离。

原`write_research_report.py`包含旧案例的固定结论，未作为新运行的报告生成器导入；改用动态结果检查器。图的数值计算保留，近入口诊断改成中性题目，避免预设新种子2必然失败。原始方案Word和第三方源码快照不是运行所需依赖，没有加入此代码仓库；保留其原始哈希来源记录，归档检查核对来源记录而不要求分发原始Word。

`reference_results`仅保存小型原结果JSON，不复制旧模型、旧NPZ数据或旧搜索检查点；这些旧文件仍在原归档。新的端到端smoke检验会真实调用PySR和MLP，但不把它当作全157次搜索的重跑。原文章、原代码与原始实验结果均保留。

所有源码和文本采用UTF-8与LF。项目带README、配置、环境说明、实验设置、测试、CI、忽略规则和Python包元数据。仓库尚无发布远程地址，也没有替作者创建GitHub发布或设定论文作者、DOI与开源许可。
